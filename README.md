# ذِكرك — الإصدار الاحترافي

> **اذكر الله يذكرك**

هذه حزمة الترقية الاحترافية لموقع «ذِكرك». تحافظ على الهوية الهادئة، وتضيف تجربة ورد يومي أكثر اكتمالًا، وشريط وصول سريع، ومفضلة واضحة، وفلاتر للدليل، ومشاركة، وتحكمًا بحجم النص، وتنقلًا سفليًا للهاتف.

## استبدال ملفات الموقع المنشور

افتح مستودع GitHub الحالي `dhikrak.1` ثم اختر **Add file → Upload files**. ارفع كل ملفات هذه الحزمة إلى **جذر المستودع**، ووافق على استبدال الملفات ذات الأسماء نفسها. لا تنشئ مجلدات، ولا ترفع ملف ZIP نفسه.

| الملف | وظيفته |
|---|---|
| `index.html` | نقطة دخول الموقع. |
| `app.js` | التجربة التفاعلية الكاملة. |
| `styles.css` | نظام الهوية والواجهة المتجاوبة. |
| `sadaqah-hero.jpg` | صورة الواجهة الرئيسية. |
| `sadaqah-mark.png` | الشعار وأيقونة الموقع. |
| `package.json` و`netlify.toml` | إعدادات البناء والنشر عبر Netlify. |

بعد رفع الملفات وعمل **Commit changes**، يبدأ Netlify النشر تلقائيًا. انتظر دقيقتين تقريبًا ثم افتح رابط الموقع أو استخدم خيار **Deploys** في Netlify للتأكد من اكتمال النشر.

## ملاحظة المحتوى

الفهرس الموسع يجلب بيانات حصن المسلم من مصدر مفتوح بترخيص MIT عند وجود اتصال بالإنترنت. تحفظ المفضلة وعداد التكرار وحجم النص محليًا على جهاز كل زائر، من دون حسابات أو إعلانات أو خادم خاص.
