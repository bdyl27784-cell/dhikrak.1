# ذِكرك

> **اذكر الله يذكرك**

هذه نسخة مستقلة كاملة من موقع «ذِكرك» مُنظَّمة في ملفات موجودة كلها في **جذر المستودع**، لتتمكن من رفعها واحدةً واحدةً من تطبيق GitHub على الهاتف. لا توجد أي مجلدات مطلوبة للنشر.

## الملفات التي يجب رفعها

| الملف | الغرض |
|---|---|
| `index.html` | صفحة الموقع الرئيسية. |
| `styles.css` | تصميم الموقع كاملًا. |
| `app.js` | الواجهة، البحث، عداد التكرار، المفضلة والوضع الليلي. |
| `sadaqah-hero.jpg` | صورة الواجهة الرئيسية. |
| `sadaqah-mark.png` | علامة ذِكرك وأيقونة الموقع. |
| `package.json` | تعريف بسيط لتشغيل البناء في Netlify. |
| `netlify.toml` | إعداد النشر التلقائي على Netlify. |
| `README.md` | هذا الدليل. |

## الرفع من الهاتف إلى GitHub

افتح المستودع الفارغ، ثم اختر **Add file** وبعدها **Upload files**. ارفع الملفات الثمانية المذكورة في الجدول واحدًا واحدًا إلى جذر المستودع، ثم اضغط **Commit changes**. لا ترفع ملف ZIP؛ المطلوب هو الملفات المفكوكة فقط.

## النشر على Netlify

من Netlify اختر **Add new project → Import an existing project → GitHub** ثم اختر مستودع `dhikrak`. اترك الإعدادات كما تظهر لأن `netlify.toml` يضبط أمر البناء ومجلد النشر تلقائيًا. اضغط **Deploy**.

## ملاحظة المحتوى

يتضمن الموقع أذكار الصباح والمساء ضمن ملف التطبيق، ويجلب الدليل الموسع من البيانات المنشورة في مشروع [HisnElMuslim](https://github.com/asellam/HisnElMuslim) بترخيص MIT عند توفر اتصال بالإنترنت. لا توجد حسابات مستخدمين أو إعلانات أو خادم خاص.
